# Tarifas importadas preautorizadas

Las tarifas FCL importadas activas en estado `PreAuthorized` son seleccionables por Pricing.

Cuando Pricing usa una tarifa `PreAuthorized` para crear una tarifa oficial, el servicio la promueve automáticamente a `Approved`. Esto no requiere el permiso de aprobación manual de importaciones, porque `PreAuthorized` representa una preautorización automática previa. Las tarifas `Pending` continúan requiriendo el permiso de aprobación correspondiente.
